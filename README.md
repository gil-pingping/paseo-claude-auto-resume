# Paseo Claude auto resume

Resume a Claude Code agent in Paseo after its five-hour session limit resets. The plugin watches for the exact limit response, waits until one minute after the stated reset time, then sends a new continuation turn to the **same agent**. It cancels the pending turn if you resume manually or archive the agent.

This version handles reset messages labelled `Asia/Seoul` within six hours. It sends a Korean continuation prompt. It does not replay the interrupted turn or its attachments.

## Install

Requires Paseo 0.11.1 or newer, an available Claude provider, and plugins enabled on the daemon host. Plugins run trusted code on that host; review the source before installing.

```bash
paseo plugin add git:gil-pingping/paseo-claude-auto-resume
paseo plugin ls claude-auto-resume
```

`running` means the hook is active. It handles new limit events from installation onward. The plugin logs `Scheduled Claude agent after usage reset` and `Resumed Claude agent after usage reset` without storing conversation text.

```bash
paseo plugin logs claude-auto-resume
```

To stop it, run `paseo plugin disable claude-auto-resume`.

## Limits

- Paseo daemon and plugin must remain running until reset. Plugin reload or daemon restart loses pending timers.
- Only top-level Claude agents are resumed. Each reset triggers at most one follow-up. A manual turn cancels a pending follow-up.
- The reset clock must be in `Asia/Seoul`; other time zones are ignored.
- Real account limits cannot be generated by the test suite. Tests use synthetic limit events. One live reset on Paseo 0.11.1 was observed on 2026-10-09: the plugin sent the follow-up at the reset time and the agent continued working.
